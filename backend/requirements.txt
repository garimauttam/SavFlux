# ── Cross-language AST chunking ───────────────────────────────────────────────
# ast_chunker.py gives Python AST-boundary chunks; every other language used
# RecursiveCharacterTextSplitter, which counts characters and cuts functions in
# half. These grammars extend AST chunking to JS/TS, and tree_sitter_langs.py
# resolves a file path to the right one.
#
# WHY PER-LANGUAGE WHEELS INSTEAD OF tree-sitter-language-pack:
# that package advertises 371 grammars in ~2.4 MB, so it does not ship them — it
# downloads each grammar on first use. `pip show tree-sitter-language-pack` then
# `get_language("typescript")` fails with DownloadError on a machine that cannot
# reach GitHub releases. Chunking quality would depend on network access at
# ingest time, in a project whose pitch is "$0, works offline". These wheels
# compile the grammar in, so parsing never touches the network.
#
# Only python/javascript/typescript are pinned. Grammars for the other languages
# ingestion accepts (go, java, rust, ruby, c, cpp) are registered in
# tree_sitter_langs.py but not installed; they resolve to None and fall back to
# the text splitter, so adding one is a single `pip install` with no code change.
tree-sitter==0.26.0
tree-sitter-python==0.25.0
tree-sitter-javascript==0.25.0
tree-sitter-typescript==0.23.2
